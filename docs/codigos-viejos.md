## Rutina corta para no trabarte con un número viejo

1. Abrí [stellatvplay.com/descargar](https://stellatvplay.com/descargar).
2. Copiá el código de tu equipo (tele o celular) o escribí la URL `/tv` o `/celular` en Downloader.
3. Si el número que tenías no coincide con el de esa página, descartalo.
4. Si el vigente tampoco baja, revisá que esté sin espacios y escribinos por el [chat](https://stellatvplay.com/soporte).

Para probar la app, pedí la [demo gratis de 6 horas](https://stellatvplay.com/soporte?demo).
