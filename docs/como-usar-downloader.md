# Cómo funciona un código en Downloader

Un código Downloader es un número corto que apunta a una dirección web. Lo escribís en la app Downloader (en el recuadro de la dirección, sin espacios) y tocás Go: la app busca esa dirección y baja el archivo de instalación (APK).

El código no es Stella TV. Si la dirección cambia, vence o la apuntan a otro archivo, el número deja de servir aunque lo hayas usado antes. Por eso este repo remite siempre a [stellatvplay.com/descargar](https://stellatvplay.com/descargar).

## Qué tenés que tener antes

- Downloader instalado: en Fire TV, desde la tienda de Amazon (buscalo con la lupa; es la app del ícono naranja). En un TV Box, una tele con Google TV o Android TV, o un celular, desde Play Store. Es gratis.
- Permiso para que Downloader instale apps de orígenes desconocidos. Se da una vez, solo para esa app.
- El código o la URL del sitio oficial, no de un video, un comentario o una lista suelta.

## Qué escribir

Al 18/11/2026, según [Descargar](https://stellatvplay.com/descargar) y [Códigos Downloader](https://stellatvplay.com/codigos-downloader):

- Tele, Fire Stick y TV Box: **1398148**, o `stellatvplay.com/tv`
- Celular y tablet: **1527904**, o `stellatvplay.com/celular`
- Si usás Unlinked en vez de Downloader: **e2012649** (sirve en TV y celulares)

Escribir la URL completa funciona igual que el número y, si dudás de un código, es la forma más clara de apuntar al sitio oficial.

## Por qué un código deja de andar

- El dueño lo apuntó a otro archivo o sacó una versión nueva con otro número.
- La dirección venció o la borraron: el número existe, pero ya no lleva a un archivo.
- Viene de un video o una lista de hace meses.
- Está mal escrito: un dígito de más o de menos lleva a otra dirección.

Si el código baja el archivo pero Android dice «Aplicación no instalada», el problema ya no es el número: suele ser falta de espacio, de permiso o un archivo incompleto. El detalle está en [stellatvplay.com/aplicacion-no-instalada](https://stellatvplay.com/aplicacion-no-instalada).

## Cómo saber si un código es el de Stella TV

1. Compáralo con los de [stellatvplay.com/descargar](https://stellatvplay.com/descargar). Esa página indica cuándo se revisaron.
2. Si no coincide, no lo uses. Los números viejos de Stella TV y uno que no es de este sitio están en [codigos-viejos.md](codigos-viejos.md).
3. En caso de duda, escribí en Downloader `stellatvplay.com/tv` o `stellatvplay.com/celular`.

Cualquiera puede crear un código para cualquier dirección (el acortador es de AFTVnews, el sitio del creador de Downloader). Que un número «funcione» no quiere decir que baje la app oficial.
